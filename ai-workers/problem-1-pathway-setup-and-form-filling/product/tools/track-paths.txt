# routes a PR by the files it touches. The one list: product/tools/track-route.py turns it into the regexes in

#   track-a: platform, audit, front-office sales and booking, web platform module.
#   track-b: client money, case side, front-office retainers and signing, platform files.

# Replaced by the path owners of #2925 when that merges (scope:<name> lines below already read .mergify.yml's scopes).

# Line forms (one per line; "#" starts a comment):
#   <track> <glob>          a glob relative to the studio folder (prefix below); ** any depth, * one name part

#   <track> scope:<name>    every include pattern of that Mergify scope in .mergify.yml (one source, no copy)
#   <track> !<glob>         an exception: never this track (a file of the other track inside a folder of this one)
