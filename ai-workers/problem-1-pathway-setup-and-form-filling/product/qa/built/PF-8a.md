PF-8a (map row 1, R1.1; runtime, the Canadian estate as code, synth only): `deploy/cdk/` holds an AWS CDK v2 app with its own exact-pinned `package.json` and lockfile, one stack per environment (`estate-staging`, `estate-production`), both pinned to `ca-central-1`: a VPC over two zones with isolated database subnets, RDS PostgreSQL 18.3 (Multi-AZ in production, single-AZ in staging), KMS-encrypted, deletion-protected, 35-day backups with point-in-time restore, `rds.force_ssl` on and terse error logs, and three buckets (documents, exports, imports) with public access blocked, versioning, KMS and a TLS-only policy. Anyone can run, with no AWS account or key: `cd deploy/cdk && npm ci --ignore-scripts && npx cdk synth --quiet && npm test` (27 checks: the region guard of C1-3 and every data rule, each with a pass and a fail case). Job `deploy-synth` in `.github/workflows/skeleton.yml` runs the same on each ready PR that changes `deploy/`. Nothing is deployed: the service, secrets and DNS are PF-8b, the deploy from CI is PF-8c.
