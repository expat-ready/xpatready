## Technology gate record: actionlint 1.7.9 for workflow lint, report-only
Read 28 Nov 2026 on github.com/rhysd/actionlint (tag `v1.7.9` = commit `a443f344ff32813837fa49f7aa6cbc478d770e62`, committed 21 Nov 2025; release asset `actionlint_1.7.9_linux_amd64.tar.gz`, sha256 `233b280d05e100837f4af1433c7b40a5dcb306e3aa68fb4f17f8a7f45a7df7b4` from the release's `actionlint_1.7.9_checksums.txt` and re-computed on the download).
* **Problem.** LR-059 asks for a workflow lint. Nothing reads our 29 workflow files for GitHub-side mistakes (an unknown runner label, a wrong `${{ }}` context, a typo in an event or input name): today they show up only when a workflow fails to start on GitHub. Our own checks (`check-*.sh`) test each workflow's intended shape, not GitHub's schema.
* **Options weighed.** (1) actionlint (MIT, single static Go binary, no runtime dependency, the common choice for this). (2) zizmor (MIT, a security auditor for workflows; Python/Rust; overlaps with what `check-workflow-security.sh` and `check-write-token.sh` already hold; a second tool, later if needed). (3) The `rhysd/actionlint` Docker image or a third-party wrapper action: more moving parts and another `uses:` to pin. (4) Nothing: keeps the gap. Chosen: (1), as a downloaded release binary checked by sha256 in the job.
* **Integration and upkeep.** One workflow, `.github/workflows/workflow-lint.yml`: runs only on a PR that changes `.github/workflows/**` or `.github/actionlint.yaml`; read-only token, no secrets, `continue-on-error` (report-only, findings in the job summary); shellcheck integration off (`-shellcheck=`, so no second tool). `.github/actionlint.yaml` lists the Mac's custom runner labels (`xr-mac`, `xr-mac-light`). On main at the time of this PR, actionlint 1.7.9 reports no findings (its only finding without the config was the unknown `xr-mac-light` label). Upgrade only through this gate: change `V` and `SUM` together.
* **Data and licence.** Reads our workflow files only; no network at run time beyond the one download from github.com; no personal data. MIT licence, a CI tool never shipped in the app, so no licence duty reaches the product (Unconfirmed: no counsel). Cost US$0.
* **When to reconsider.** After 10 clean runs (or 24 h), a later PR may make it blocking (drop `continue-on-error`) and add it to a required check. Drop it if it raises more than about one false finding a week, or replace with zizmor if a security-focused lint is wanted.
