Contract used (shape only)

  • GET /api/platform/custom-fields/values/fo_prospect/:id and …/fo_person/:personId (or fo_company) → { fields[], values, canEdit, version }; one request per kind on the screen view.
  • PUT …/values/:kind/:id { values: {key: value|null}, version } → 422 Problem Details with errors[] by key (said at the field) · 403 · 404 · 409 STALE (frame H). Empty value = null (no row).
  • Two kinds on one panel save as two PUTs; if the second fails the first stays saved and the panel says which group did not save.
