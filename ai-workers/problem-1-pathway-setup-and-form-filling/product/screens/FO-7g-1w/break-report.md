* **Reproduction:** start with firm A not registered and "Prices include tax" off. Connection 1 runs `select … from money_invoice where id=$1 for update` and holds it. Then POST a FEE line with no rate; it passes settingsOrRefuse and waits on the lock. Connection 2 runs `update money_payment_settings set tax_registered = true, prices_include_tax = true` in one statement. Connection 1 commits.

### m2. Minor (only reachable inside the process): `ratePpm: undefined` counts as "not taxable", not "nothing sent"
* **File:** `drafts.ts:82` asks `Object.hasOwn(body, "ratePpm")`. Then `LineIn`'s `.default(0)` (`ports/client-money.ts:40`) turns `undefined` into 0, so `:100` stores 0.
