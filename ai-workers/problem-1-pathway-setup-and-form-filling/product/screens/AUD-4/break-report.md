## What held
* **Roles:** Owner and Admin get 200 on both routes. Case Officer, Case Manager, Read-only and Billing get 403 `MISSING_PERMISSION` on both. An Admin whose grant was ended gets 403. **The deactivated Owner's token gets 401 `STAFF_NOT_ACTIVE`**. No token or a garbage token gets 401. None of the refused callers wrote an export line.
* **Firm B reading A:** tried `?firmId=A`, `?firm=`, `?firmKey=sample-firm`, `?workspace=`, `x-firm-id`/`x-firm-key` headers, `person=` set to A's Owner or Case Officer, `entityKey=A`, a cursor naming A's line, and an export with `?firmId=A`. Every answer held only B's lines. B's `people` had only B's staff. Mirrored for A against B: a cursor with B's line at the **same `at`** as 60 of A's lines, and `person=<S.id>` (also in upper case), gave 0 B lines.
* **Platform line** (`firm_id` null) about A: absent from every page and from `actions`. B-only actions never appeared in A's `actions`.
* **Cursor:** garbage, `%%%`, 8k characters, injection text in `at` or `id`, an object, a number and `null` all gave 400 BAD_CURSOR. 40k characters gave 431 (Node's header limit).
* **Dates:** exactly one year gives 200. One year plus a microsecond gives 400 (6-digit fractions refused). Plus a millisecond gives 400 RANGE_TOO_LONG. Reversed or equal ranges give 400. A date without a zone, a space separator, `20260101`, `2026-1-1`, epoch numbers, full-width digits and a repeated `from` all give 400. Missing or empty dates give 400 DATES_REQUIRED. `+05:30`, `-00:00`, and `+14:00` to `-12:00` were each checked by the real moment.
* **Filters:** SQL metacharacters in action, entity and entityKey are bound as parameters and match nothing (the table is intact). `actorType` outside the list, in lower case, or `toString` gives 400. Values over 200 characters give 400. Unknown params (`limit=100000`, `page`, `sort`, `__proto__`) are ignored and the page stays at 50.
* **CSV:** a 16-line export gave `X-Export-Rows: 16` and parsed to exactly 17 rows of 13 cells. `'` is prefixed where a summary, entity key, changes cell or the person's name (`=HYPERLINK…`) starts with `=`, `@`, `+`, `-`, tab or CR. Quotes are doubled. LF, CRLF and commas round-trip. Unicode, 600- and 20,000-character summaries are intact. The file is UTF-8 with a BOM.
* **Two exports racing 777 new in-range lines:** each header was 100,000, each file had 100,000 data rows, and 0 race lines were in either file. Each wrote one line with `rows: 100000`. A third export, opened after the race lines, got 413 (it would have held 100,777). No line was written for the 413, as specified.
* **Abort:** after an abort the transaction was released (no `idle in transaction` left), the API stayed up, and the next page (94 ms) and a full export (88,268 rows) worked.
